# Analyzing the Post-Pandemic Fluctuation of Metro Rail Ridership in Los Angeles County

## Project Overview

This project analyzes how LA Metro rail ridership in Los Angeles County has changed since the COVID-19 pandemic. It examines ridership trends from 2019 to 2026 and explores whether recent developments in the Metro system have influenced the recovery of public transportation usage.

## Files

- 00_requirements.R - Loads and checks the required R packages for the project.
- 01_funct_datacleaning.R - Contains functions used to clean and prepare the ridership dataset for analysis.
- 02_funct_Plots.R - Contains functions used to create the data visualizations.
- 11_DataCleaning.Rmd - R Markdown file documenting the data cleaning and preparation process.
- 31_DataVisualization.Rmd - R Markdown file containing the data analysis and visualizations.
- FinalReport.Rmd - R Markdown file containing the final project report, including the research question, methodology, findings, and conclusions.
- metro_ridership.csv - The dataset containing LA Metro ridership information used for this project.
- README.md - Provides an overview of the project files and instructions for reproducing the results.

## How to Reproduce the Results

1. Download or clone this repository to your computer.
2. Open RStudio and open the project folder.
3. Set the working directory to the folder containing the project files.
4. Open 00_requirements.R and run the script to check and load the required packages.
5. Open 11_DataCleaning.Rmd`and run the code chunks to clean and prepare the dataset.
6. Open `1_DataVisualization.Rmd and run the code chunks to perform the analysis and generate the visualizations.
7. Open FinalReport.Rmd and click Knit to generate the final report.
8. Review the generated report and visualizations to examine the findings.

## Research Question

How has LA Metro rail ridership in Los Angeles County changed since the COVID-19 pandemic, and to what extent have recent developments influenced its recovery compared to pre-pandemic levels?
